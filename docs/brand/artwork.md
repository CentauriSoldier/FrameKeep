# FrameKeep artwork

Created specifically for this project with the built-in image generation tool. No existing brand artwork was supplied; the generated icon was the reference for the banner. This is original project artwork, not a claim of worldwide trademark uniqueness or legal clearance.

- Icon: [framekeep-icon.png](framekeep-icon.png)
- README banner: [framekeep-banner.png](framekeep-banner.png)

## Icon prompt

Use case: logo-brand. Asset type: square repository icon for FrameKeep, a local video library organized with tags and playlists. Create an original polished geometric emblem: an asymmetric interlocking pair of luminous cyan and violet frame brackets enclosing three offset film frames, with a small bookmark-like notch suggesting keeping and organizing moments. Bold recognizable silhouette readable at small sizes, balanced negative space, restrained smooth beveled surfaces, dark midnight background matching a dark video-library UI. No words, no stock play triangle as the main logo, no resemblance intentionally to existing media-player brands, no existing logos, no watermarks. One centered icon, generous margin, square 1024x1024 composition.

## Banner prompt

Use case: logo-brand. Asset type: wide GitHub README banner for FrameKeep. Input image is a brand reference: preserve its distinctive cyan/violet frame brackets, stacked film frames, and bookmark notch as the emblem. Create a polished original wide 3:1 composition on a dark midnight background. Emblem in the left third; crisp large typography to its right reading exactly 'FrameKeep', and beneath it smaller text exactly 'Your videos. Your tags. Your playlists.' Elegant restrained luminous frame-line accents across the background; plenty of breathing room, no screenshots or fake UI, no existing brands, no stock logos, no watermark. High readability at README width. Match the supplied emblem's design and palette.
